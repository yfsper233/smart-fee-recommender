# 项目说明

- 名称：智能费率推荐（smart-fee-recommender）。
- 本期目标：将实时费率 demo 整理为独立公开项目，具备可复现验证与 Cloudflare Workers 静态部署条件。
- 部署形态：Workers Static Assets，浏览器直接订阅 mempool 并执行纯函数。
- 当前阶段：仓库初始化；Cloudflare 部署单独执行。

## 范围

保留单步最优、累计均值最优、共同最低优先级与 95% 搜索边界；保留实时费率分布、两种选点与效率图，以及必要计算口径。

本期不引入历史数据存储、钱包签名、自动广播、服务端计算或确认概率模型。

## 验收标准

- 单步最优与累计均值最优使用同一份候选区块数据。
- 严格低费率比较、0.01 sat/vB 档位、较低费率并列优先、95% 档位整体计入。
- 断线、同步中、空数据、数据过期不展示有效推荐。
- 两种算法的累计指标统一从最低达标费率计算。
- `npm run verify` 与 `npm run deploy:check` 通过。
- GitHub Actions 验证通过。
- Cloudflare 上线后验收 HTTPS、模块 MIME、响应头、实时订阅及重新同步。

## 里程碑

1. 仓库初始化：独立目录、源码、算法测试、构建、CI、部署配置与说明。
2. 静态上线：选择 Cloudflare 账号，连接仓库并发布至 workers.dev。
3. 上线验收：核对资源与算法展示；如有需要再接入自定义域名。
